# MERCHROOM

E-Commerce Web Application for Merchandise & Collectibles.

## Features
- Storefront & Product Catalogue (Thai Heritage, Pop Culture, Artists)
- User Authentication (Login, Register, Forgot Password, Reset Password)
- Customer Account Dashboard (Profile Settings, Order History, Wishlist, Payment Methods)
- Admin Dashboard
- Cart & Checkout System

## Tech Stack
- Frontend: React, React Router, Tailwind CSS, Vite
- Backend: Node.js, Express
